# 🎢 3D 过山车模拟器

基于 **Three.js + Vite** 的交互式 3D 过山车模拟器（多文件工程）。

## 功能特性

- **轨道系统**：CatmullRom 闭合样条生成轨道，包含爬坡、俯冲、弯道、竖直回环；按轨道高度自动生成支撑立柱
- **重力物理**：重力沿轨道切线投影，上坡减速、下坡加速，含摩擦阻力与爬坡链条提升机；支持启停、速度倍率（0.2×–3×）、单圈 / 循环运行
- **相机系统**：透视 / 正交一键切换、OrbitControls 自由拖拽缩放、车头跟随视角（回环时相机同步翻转）
- **线框模式**：一键查看轨道骨架结构
- **天气系统**：晴天 / 阴天 / 黄昏 / 雨夜 / 夜晚五种预设，配套实时光照、PCF 软阴影、雾效、下雨粒子
- **资源兜底**：天空盒纹理与 GLTF 模型均从 CDN 在线加载，加载失败自动降级为渐变天穹与几何体雕塑

## 环境要求

- Node.js ≥ 18（建议 LTS 版本）
- 联网（首次安装依赖、运行时加载 CDN 上的天空盒纹理与 GLTF 模型；离线时自动使用兜底资源，不影响运行）

## 安装

```bash
npm install
```

## 启动开发服务器

```bash
npm run dev
```

启动后自动打开浏览器（默认 http://localhost:5173）。

## 构建与预览

```bash
npm run build      # 打包到 dist/
npm run preview    # 本地预览构建产物
```

## 操作说明

| 操作 | 说明 |
| --- | --- |
| 鼠标左键拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| 鼠标右键拖拽 | 平移 |
| ▶ 启动 / ⏸ 停止 | 控制列车运行 |
| 速度倍率滑块 | 0.2× – 3× 调速 |
| 循环运行 | 关闭后列车跑完一圈自动停靠站台 |
| 透视 / 正交 | 切换相机投影方式 |
| 跟随车厢视角 | 相机挂在车头后上方跟拍 |
| 线框透视 | 查看轨道骨架 |
| 天气按钮 | 切换晴天 / 阴天 / 黄昏 / 雨夜 / 夜晚 |

## 目录结构

```
├── index.html              # 页面骨架与控制面板 DOM
├── package.json
├── vite.config.js
└── src/
    ├── main.js             # 主入口：组装子系统、渲染循环
    ├── style.css           # 界面样式
    ├── config.js           # 天气预设 / 物理常量 / 资源地址
    ├── core/
    │   ├── Stage.js        # 渲染器、场景、灯光
    │   └── CameraRig.js    # 透视/正交相机、轨道控制、跟随视角
    ├── world/
    │   ├── Track.js        # 轨道曲线、钢轨、枕木、支架
    │   ├── Coaster.js      # 车厢编组与重力物理
    │   ├── Environment.js  # 地面、站台、天空盒、GLTF 装饰（含兜底）
    │   └── Weather.js      # 天气切换与下雨粒子
    └── ui/
        └── ControlPanel.js # 控制面板事件绑定
```
